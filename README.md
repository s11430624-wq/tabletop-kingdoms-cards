# Tabletop Kingdoms 卡牌工坊

我開發中的 Godot 遊戲《Tabletop Kingdoms》的卡牌圖鑑與牌組工坊，用 Vibe Coding 做成單檔網頁。

- 網站：https://s11430624-wq.github.io/tabletop-kingdoms-cards/
- 規格書：[SPEC.md](SPEC.md)
- 程式：[index.html](index.html)（CSS、JavaScript、卡牌資料全部內嵌）

功能：40 張卡的搜尋／篩選／排序、各形態數值與差異、最多 3 張卡並排比較、8 張牌組的拖曳組牌與自動分析、網址分享、瀏覽器存檔、淺色／深色主題、手機版。
